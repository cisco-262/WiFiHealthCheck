关于 WiFi Health Check

WiFi Health Check 是 OpsHome 构建的一款专注于 WiFi 和局域网快速排障的 iPhone App。

WiFi Health Check 是什么

WiFi Health Check 帮助用户从 iPhone 理解常见 WiFi 问题。它检查公网连通性、DNS 表现、当前 WiFi 上下文，例如 SSID、BSSID 和安全类型、本地网关上下文、局域网设备发现、自定义局域网 TCP 可达性，以及 WiFi 漫游行为。

为什么需要它

WiFi 问题往往很难描述。一份简单的本地报告可以显示问题是外部连通性、局域网端点、网关配置、WiFi 安全上下文，还是接入点之间的漫游。

它不会做什么

WiFi Health Check 不是抓包工具，也不会声称能够读取普通 App Store 应用无法从 iOS 稳定获得的无线指标，例如 RSSI、信道、频段、信道宽度或 PHY 速率。它更关注可观察到的连通性、DNS、TCP、设备发现、延迟、超时和漫游行为。
