WiFi Health Check

隐私政策

WiFi Health Check 被设计为本地前台诊断 App。诊断报告默认保存在设备上，除非你主动分享。

1. 概览

WiFi Health Check 帮助用户运行本地 WiFi 和局域网诊断，包括公网网站可达性、当前 WiFi 上下文、网关信息、局域网设备发现、自定义 TCP 稳定性测试和 WiFi 漫游报告。

2. 在设备上处理的数据

App 可能在你的 iPhone 本地处理以下信息：

  • 当 iOS 提供时，当前 WiFi 的 SSID、BSSID 和安全类型
  • 本地 IP 地址和估算网关地址
  • 公网网站连通性测试结果
  • 你输入的自定义局域网目标 IP 地址和 TCP 端口
  • 局域网扫描结果，例如发现的本地 IP 地址和常见开放服务端口
  • 诊断历史、稳定性样本和漫游样本
  • 语言偏好和本地保存的报告历史

3. 位置权限

iOS 要求 App 获得位置权限，才能访问当前 WiFi 信息，例如 SSID、BSSID 和安全类型。WiFi Health Check 仅使用该权限来显示和记录当前网络上下文。App 不需要你的物理位置历史。

4. 云端与账号

WiFi Health Check 不要求注册账号，也不会把诊断历史上传到云服务。只有当你明确通过 iOS 分享时，报告才会离开设备。

5. 我们不收集的数据

  • 不收集路由器密码
  • 不收集 WiFi 密码
  • 不收集 RSSI、信道、频段或 PHY 速率，因为 iOS 不向普通 App Store 应用提供这些值
  • 不收集抓包数据
  • 不收集浏览历史
  • 不要求注册账号身份

6. 支持

如有隐私相关问题，请联系 OpsHome 支持。请不要发送 WiFi 密码、路由器管理密码或私有网络凭据。
