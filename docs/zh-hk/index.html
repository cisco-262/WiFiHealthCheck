常见問題

为什么 App 要求位置权限？

iOS 将 WiFi SSID、BSSID 和当前網絡详情放在位置权限以及 WiFi 信息能力之后。App 只用这些信息显示当前連線的 WiFi 名称、节点标识和安全类型。

网关 TCP 探测失败是否代表断网？

不是。路由器可能使用自定义端口或关闭常见端口。WiFi Health Check 使用公网网站可达性作为主要互联网信号，网关 TCP 状态仅作辅助上下文。

BSSID 不可用是什么意思？

这表示 iOS 没有向 App 提供 WiFi 节点标识。原因可能是模拟器、蜂窝網絡、缺少权限、能力限制或系统私隱限制。

App 能显示 WiFi 信号强度或信道吗？

iOS 不会向普通 App Store 應用程式可靠提供 RSSI、信道、频段、信道宽度或 PHY 速率。WiFi Health Check 会展示 iOS 允许的信息，并用连通性、DNS、TCP、延迟、超时和漫游行为診斷真实網絡体验。

區域網絡掃描可以發現什么？

區域網絡掃描会檢查当前 WiFi 子网中的可达設備和常见开放服務端口，可辅助识别 NAS、Proxmox、打印机、文件共享、Web 管理等服務。不同 VLAN、客户端隔离、設備防火墙和網絡分段可能限制可见范围。

可以测试自定义网关或 NAS 端口吗？

可以。區域網絡 TCP 穩定性测试允许输入 IP 地址和 TCP 端口进行重复连通性采样。

它能替代长期监控吗？

不能。它是前台本機診斷工具。如果需要持续可用性、Docker、Synology、Proxmox、Linux 主机或私有基础设施监控，请使用 OpsHome NOC。

需要持续基础设施监控？

WiFi Health Check 用于本機前台診斷。OpsHome NOC 用于持续监控服務、Docker、Synology、Proxmox、Linux 主机、私有端点、告警和历史數據。
