WiFi Health Check 如何工作

在 WiFi 下開啟 App

使用連線到 WiFi 的實體 iPhone。iOS 可能需要位置權限才能提供 SSID、BSSID 和安全類型。

執行專項測試

根據問題選擇一鍵診斷、區域網絡掃描、區域網絡 TCP 穩定性或漫遊測試。

查看本機結果

理解公網可達性、DNS 目標、發現到的區域網絡裝置和服務、WiFi 安全類型、網關上下文、自訂連接埠穩定性和漫遊路徑變化。

只在需要時分享

報告會保留在你的裝置上，除非你明確透過 iOS 分享。

判斷問題來自互聯網、區域網絡還是漫遊

家庭或辦公室 WiFi 問題可能來自寬頻、DNS、路由器 WAN、區域網絡裝置可達性、弱訊號，或用戶端黏在錯誤的存取點上。

WiFi Health Check 會把這些訊號拆成小報告，方便你在不同位置之間對比。

常見問題

為甚麼 App 要求位置權限？

iOS 將 WiFi SSID、BSSID 和目前網絡詳情放在位置權限以及 WiFi 資訊能力之後。App 只用這些資訊顯示目前連線的 WiFi 名稱、節點識別碼和安全類型。

網關 TCP 探測失敗是否代表斷網？

不是。路由器可能使用自訂連接埠或關閉常見連接埠。WiFi Health Check 使用公網網站可達性作為主要互聯網訊號，網關 TCP 狀態僅作輔助上下文。

BSSID 不可用是甚麼意思？

這表示 iOS 沒有向 App 提供 WiFi 節點識別碼。原因可能是模擬器、流動網絡、缺少權限、能力限制或系統私隱限制。

App 能顯示 WiFi 訊號強度或頻道嗎？

iOS 不會向一般 App Store 應用程式可靠提供 RSSI、頻道、頻段、頻道寬度或 PHY 速率。WiFi Health Check 會展示 iOS 允許的資訊，並用連通性、DNS、TCP、延遲、超時和漫遊行為診斷真實網絡體驗。

區域網絡掃描可以發現甚麼？

區域網絡掃描會檢查目前 WiFi 子網中的可達裝置和常見開放服務連接埠，可輔助識別 NAS、Proxmox、印表機、檔案共享、Web 管理等服務。不同 VLAN、用戶端隔離、裝置防火牆和網絡分段可能限制可見範圍。

可以測試自訂網關或 NAS 連接埠嗎？

可以。區域網絡 TCP 穩定性測試允許輸入 IP 地址和 TCP 連接埠進行重複連通性採樣。

它能替代長期監控嗎？

不能。它是前台本機診斷工具。如果需要持續可用性、Docker、Synology、Proxmox、Linux 主機或私有基礎設施監控，請使用 OpsHome NOC。

需要持續基礎設施監控？

WiFi Health Check 用於本機前台診斷。OpsHome NOC 用於持續監控服務、Docker、Synology、Proxmox、Linux 主機、私有端點、告警和記錄資料。
