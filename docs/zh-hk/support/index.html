WiFi Health Check

支援

此頁面提供產品支援、排障方向，以及 iOS WiFi 資訊限制說明。

聯絡方式

如需 WiFi Health Check 支援，請透過 support@opshome.run 聯絡 OpsHome。

請提供 App 版本、iOS 版本、裝置型號和簡短問題描述。請不要發送 WiFi 密碼、路由器管理密碼或私有憑據。

常見排障說明

  • 如果 SSID、BSSID 或 WiFi 安全類型不可用，請確認你使用的是實體 iPhone 且已連線 WiFi，而不是模擬器或流動網絡。
  • 如果你希望 App 讀取目前 WiFi 詳情，請允許位置權限。iOS 要求此權限才能訪問 WiFi 識別碼和相關目前網絡資訊。
  • 網關 TCP 連接埠關閉並不自動代表互聯網故障。請將公網網站連通性作為主要互聯網訊號。
  • 對於區域網絡 TCP 穩定性測試，請輸入路由器、NAS、印表機、AP 或伺服器實際使用的自訂連接埠。
  • 區域網絡掃描只檢查目前 WiFi 子網，其他 VLAN 或通過路由訪問的子網裝置可能不會出現。
  • 用戶端隔離、網絡分段、裝置防火牆、休眠狀態和關閉的服務連接埠都可能限制區域網絡掃描結果。
  • 進行漫遊測試時，請在 WiFi 節點之間移動，並保持 App 在前台執行。
  • iOS 不會向一般 App Store 應用程式暴露可靠的 RSSI、頻道、頻段、頻道寬度或 PHY 速率。請使用 App 的 DNS、TCP、延遲、超時和漫遊結果理解連線質量。

何時使用 OpsHome NOC

如果你需要持續監控、告警、Docker Probe、Synology、Proxmox、Linux 主機監控、私有服務檢查或記錄基礎設施儀表板，請使用 OpsHome NOC。
