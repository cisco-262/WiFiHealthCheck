WiFi Health Check

支援

此页面提供产品支援、排障方向，以及 iOS WiFi 信息限制说明。

联系方式

如需 WiFi Health Check 支援，请通过 support@opshome.run 联系 OpsHome。

请提供 App 版本、iOS 版本、設備型号和简短問題描述。请不要发送 WiFi 密码、路由器管理密码或私有凭据。

常见排障说明

  • 如果 SSID、BSSID 或 WiFi 安全类型不可用，请确认你使用的是真实 iPhone 且已連線 WiFi，而不是模拟器或蜂窝網絡。
  • 如果你希望 App 读取当前 WiFi 详情，请允许位置权限。iOS 要求此权限才能访问 WiFi 标识符和相关当前網絡信息。
  • 网关 TCP 端口关闭并不自动代表互联网故障。请将公网网站连通性作为主要互联网信号。
  • 对于區域網絡 TCP 穩定性测试，请输入路由器、NAS、打印机、AP 或服務器实际使用的自定义端口。
  • 區域網絡掃描只檢查当前 WiFi 子网，其他 VLAN 或通过路由访问的子网設備可能不会出现。
  • 客户端隔离、網絡分段、設備防火墙、休眠状态和关闭的服務端口都可能限制區域網絡掃描结果。
  • 进行漫游测试时，请在 WiFi 节点之间移动，并保持 App 在前台运行。
  • iOS 不会向普通 App Store 應用程式暴露可靠的 RSSI、信道、频段、信道宽度或 PHY 速率。请使用 App 的 DNS、TCP、延迟、超时和漫游结果理解連線质量。

如果你需要持续监控、告警、Docker Probe、Synology、Proxmox、Linux 主机监控、私有服務檢查或历史基础设施仪表盘，请使用 OpsHome NOC。
