WiFi Health Check

私隱政策

WiFi Health Check 被設計為本機前台診斷 App。診斷報告默認保存在裝置上，除非你主動分享。

1. 概覽

WiFi Health Check 幫助使用者執行本機 WiFi 和區域網絡診斷，包括公網網站可達性、目前 WiFi 上下文、網關資訊、區域網絡裝置發現、自訂 TCP 穩定性測試和 WiFi 漫遊報告。

2. 在裝置上處理的資料

App 可能在你的 iPhone 本機處理以下資訊：

  • 當 iOS 提供時，目前 WiFi 的 SSID、BSSID 和安全類型
  • 本機 IP 地址和估算網關地址
  • 公網網站連通性測試結果
  • 你輸入的自訂區域網絡目標 IP 地址和 TCP 連接埠
  • 區域網絡掃描結果，例如發現的本機 IP 地址和常見開放服務連接埠
  • 診斷記錄、穩定性樣本和漫遊樣本
  • 語言偏好和本機保存的報告記錄

3. 位置權限

iOS 要求 App 獲得位置權限，才能存取目前 WiFi 資訊，例如 SSID、BSSID 和安全類型。WiFi Health Check 僅使用該權限來顯示和記錄目前網絡上下文。App 不需要你的物理位置記錄。

4. 雲端與帳戶

WiFi Health Check 不要求註冊帳戶，也不會把診斷記錄上傳到雲端服務。只有當你明確透過 iOS 分享時，報告才會離開裝置。

5. App 不收集的資料

  • 不收集路由器密碼
  • 不收集 WiFi 密碼
  • 不收集 RSSI、頻道、頻段或 PHY 速率，因為 iOS 不向一般 App Store 應用程式提供這些數值
  • 不收集抓包資料
  • 不收集瀏覽記錄
  • 不要求註冊帳戶身分

6. 網站分析

WiFi Health Check 網站使用 Yandex Metrica 進行基礎網站分析，例如頁面瀏覽、流量來源和頁面互動統計。網站統計與 WiFi Health Check App 彼此獨立，不會接收 App 的 WiFi 診斷報告、區域網絡掃描結果或本機保存的診斷記錄。

7. 支援

如有私隱相關問題，請聯絡 OpsHome 支援。請不要發送 WiFi 密碼、路由器管理密碼或私有網絡憑據。
