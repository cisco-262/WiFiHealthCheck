WiFi Health Check

私隱政策

WiFi Health Check 被设计为本機前台診斷 App。診斷報告默认保存在設備上，除非你主动分享。

1. 概览

WiFi Health Check 帮助用戶运行本機 WiFi 和區域網絡診斷，包括公网网站可达性、当前 WiFi 上下文、网关信息、區域網絡設備發現、自定义 TCP 穩定性测试和 WiFi 漫游報告。

2. 在設備上处理的數據

App 可能在你的 iPhone 本機处理以下信息：

  • 当 iOS 提供时，当前 WiFi 的 SSID、BSSID 和安全类型
  • 本機 IP 地址和估算网关地址
  • 公网网站连通性测试结果
  • 你输入的自定义區域網絡目标 IP 地址和 TCP 端口
  • 區域網絡掃描结果，例如發現的本機 IP 地址和常见开放服務端口
  • 診斷历史、穩定性样本和漫游样本
  • 语言偏好和本機保存的報告历史

3. 位置权限

iOS 要求 App 获得位置权限，才能访问当前 WiFi 信息，例如 SSID、BSSID 和安全类型。WiFi Health Check 仅使用该权限来显示和记录当前網絡上下文。App 不需要你的物理位置历史。

4. 云端与账号

WiFi Health Check 不要求注册账号，也不会把診斷历史上传到云服務。只有当你明确通过 iOS 分享时，報告才会离开設備。

5. 我们不收集的數據

  • 不收集路由器密码
  • 不收集 WiFi 密码
  • 不收集 RSSI、信道、频段或 PHY 速率，因为 iOS 不向普通 App Store 應用程式提供这些值
  • 不收集抓包數據
  • 不收集浏览历史
  • 不要求注册账号身份

6. 支援

如有私隱相关問題，请联系 OpsHome 支援。请不要发送 WiFi 密码、路由器管理密码或私有網絡凭据。
